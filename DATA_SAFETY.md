# Data Safety Notes

Use this document to prepare the Play Console Data Safety form.

- Data stored on device: Warranty items, attachments (photos, receipts), user-provided text (names, notes).
- Data encrypted: account credentials stored in EncryptedSharedPreferences.
- Data shared: Export/Import allows manual sharing of backups; app does not automatically transmit data.
- Third-party services: None by default (no analytics, no remote sync).

Update this document before submitting to Play Store.
